# IceStream – Real-Time Lakehouse Observability

A real-time lakehouse observability platform for monitoring streaming data quality, detecting anomalies and schema drift, automatically routing bad data to a Dead Letter Queue, and visualizing pipeline health.

## Tech Stack

- Python
- Apache Kafka
- Apache Flink
- Apache Iceberg
- FastAPI
- WebSockets
- React
- React Flow
- Docker
